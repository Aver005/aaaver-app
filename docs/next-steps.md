Файл для того, кто продолжает редизайн с текущей точки. Контекст, решения и
находки — в [redesign.md](redesign.md); здесь — состояние, чеклист
недоделанного и точные следующие шаги. Обновляй этот файл по мере работы.

## Основная работа: три варианта дизайна

Каждый вариант — своя ветка от `redesign/base`, меняет только `ui/`
виджетов, `shared/ui`, `app/styles/*.css`, `App.tsx`. Модель, контент,
фича окна демки, хуки и словарь — общие; их правки делаются в базе, а
ветки ребейзятся (не cherry-pick). Подписи, нужные одному варианту, —
инлайн через `lx({ ru, en })` в его слайсе, не в общий словарь.

Держать: три семейства шрифтов без новых пакетов (Unbounded 200–900,
Golos Text 400–900, JetBrains Mono 100–800), правило чисел, зерно ≤ 4% и
только на тёмном, радиус ≤ 6px, одна линия `--color-line`, ритм 8px.
Проверено: Unbounded 200–300 на кириллице при 64px+ читается хорошо.

### A — `redesign/workbench` («верстак»), делать первым

Эволюция нынешнего: тёплый уголь, костяной текст, ember. Меняется
структура и плотность.

- Новый виджет `widgets/rail`: на `lg+` вертикальная рейка слева
  (~56px) **вместо** верхнего меню — логотип, номера и подписи разделов
  (`writing-mode: vertical-rl`), RU/EN внизу; активный пункт ember,
  остальные кость 40%. `Navbar` остаётся только для `< lg` (бургер).
  Контент получает `lg:pl-14`, статус-бар — `lg:left-14`. Без полосы
  прогресса: активный пункт и есть прогресс.
- Hero: имя `clamp(3rem, 10vw, 9rem)`, имя 800, фамилия 200–300;
  спецификация справа как сейчас; строка «открыт к задачам» внизу hero
  на `lg` скрыта (её роль у статус-бара).
- Пластины на 12 колонках, желоб 24px, медиа 7 + текст 5, строки фактов
  32px с волосяной линией, без рамок-карточек. **Первая пластина (craws)
  работает сама**: вместо скриншота — живая миниатюра демки (iframe
  `/craws/` шириной 200% с `transform: scale(0.5)`, монтируется по
  `useInView` из `motion/react` с `once: true`, только на десктопе,
  на мобильном — скриншот; клик открывает окно).
- Лента Open Source — строки (уже есть), опыт — таблица (уже есть),
  контакт — та же форма плотнее, футер — колофон.
- Motion: стаггер в hero, `Reveal` на секциях, hover на медиа — мягкий
  `scale(1.02)`, ничего сверх.

### B — `redesign/terminal` («терминал»)

Не окно с кружочками, а типографическая система на символьной сетке
(`ch` × `lh`): структура в JetBrains Mono, проза — Golos.

- Палитра по умолчанию — фирменная ember на тёплом угле; пресеты
  `midnight` (палитра из `pooprusteek/src/tui/theme.rs`: `#0B0E19`,
  акцент `#60A5FA`, статусы Catppuccin) и `paper` — как демонстрация
  движка тем. Три пресета, не восемь. Выбор в `localStorage`,
  переключение через `data-theme` на `html` и переопределение токенов
  в `theme.css`. Все цвета через токены — никаких `rgba(255,93,31,…)`
  в классах.
- Одна командная строка в статус-баре, как `:` в vim, с кликабельными
  подсказками-чипами (`projects · open craws · lang en · theme midnight`):
  команды `help`, `ls`, `cat <раздел>`, `open <slug>` (только слаги из
  `useLiveSites`, открывает `demoWindow.open`), `lang`, `theme`. На
  мобильном ввода нет — только чипы. Парсер — в `widgets/console/model`,
  чистые функции, тесты через `bun test`.
- Разделы как «файлы» (`~/projects/`, `~/experience.md`), проекты —
  таблица в духе `ls -la` (имя · язык · статус · обновлён) с раскрытием
  строки; на 390px — две колонки.
- Контакт = промпт: форма как строка `>`, ползунок slide-to-send — её
  Enter. Без псевдографики `┌┐`, без сканлайнов и мерцания.

### C — `redesign/paper` («бумага»)

Единственный светлый. Бумага `#EDEAE3`, карточки `#F6F4EE`, чернила
`#1A1916`, второй тон `#56514A`, линия `#D6D0C5`; акцент `#B8401A` для
крупного и `#9E3413` для мелкого моно (AA на бумаге). Зерна нет, меток
обрезки и фолио нет, `§` нет.

- Мера текста 66–72ch, базовая сетка 28px, кикеры JetBrains Mono 11px с
  разрядкой, висячая пунктуация где возможно.
- **Маргиналии** — заметки на полях в моно-акценте рядом с пластинами
  («почему Bun без фреймворка →»), как ADR автора; это подпись варианта.
- Графитовые полосы `#1E1C18` на всю ширину под окна демок и форму
  (демки тёмные — и полосы тёмные); тень модалок — свой `--shadow-overlay`.
- Колофон в футере, живой статус-бар — статичной строкой под hero.

### Порядок

A → ревью тремя агентами (код, визуал, продукт) → правки → коммит →
B → ревью → C → ревью → итоговая сводка автору с выбором варианта.
Каждый вариант снимать в Playwright: десктоп и мобильный по секциям,
RU и EN, `reducedMotion: 'reduce'`.

## Приёмка варианта

1. `bun run typecheck`, `bun run build`; JS ≤ 150 KB gz, CSS ≤ 25 KB,
   ноль новых семейств шрифтов и зависимостей.
2. Reduced motion: секции видны без прокрутки, бегущие строки выключены.
3. Клавиатура: Tab по навигации, карточкам, окну демки (открыть, закрыть,
   фокус вернулся), ползунку отправки; при открытом окне фон `inert`.
4. RU/EN на 1440 и 390px: длинные слова в дисплейном шрифте не
   переполняют, статус-бар не режется.
5. В данных нет непроверяемых чисел; снимок репозиториев перегенерирован
   (`bun scripts/repos-snapshot.ts`).
6. Смоук формы с локальной базой: `bun scripts/smoke-test.ts http://localhost:3001`.
