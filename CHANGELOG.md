# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по датам выкладок.

## [Unreleased]

### Добавлено

- Окно демки: живые демки из `sites/` открываются внутри сайта в iframe,
  «назад» и Esc закрывают, фокус возвращается на ссылку
  (`features/demo-window`).
- Общая модальная оболочка `shared/ui/Overlay` (портал, `inert`,
  блокировка прокрутки, возврат фокуса) — на ней согласие и окно демки.
- Статус-бар на десктопе: последний пуш на GitHub, время автора, статус.
- Спецификация в hero: роль, «сейчас» из GitHub, языки, этот сайт,
  вне кода.
- Реестр разделов `shared/config/sections.ts`; подсветка активного раздела
  в навигации.
- Модель проекта: вид, статус, период, роль, стек, факты, ссылки
  раздельно, галерея; витрина в два яруса (пластины и строки); новые
  проекты — craws, diary, root-panel, tg-multi-tool, kiviuly, flowest,
  dot-memories-ext, glw, ins, deep-reverse, плагины Minecraft.
- Строка Maushi в опыте (фриланс с 2025).
- Схема архитектуры вместо скриншота у проектов без экрана (diary).
- `scripts/repos-snapshot.ts` — снимок репозиториев тем же фильтром, что
  у сервера; `GITHUB_TOKEN` поднимает лимит API, кэш дублируется в памяти.
- `docker-compose.dev.yml` и `bun run dev:db` — локальный Postgres для
  разработки.
- `docs/redesign.md` — журнал редизайна: находки, план, решения.

### Изменено

- Структура главной: hero → проекты → опыт → open source → контакт;
  секции «Обо мне» и «Стек» убраны, их содержание — в hero и пластинах.
- Тексты hero: лид про инструменты, которыми автор пользуется сам.
- Open Source — строки с языком и датой пуша вместо плиток; звёзды
  показываются от десяти; подпись «снимок от даты», если GitHub недоступен.
- Футер — колофон: чем набрано и на чём работает.
- Палитра вынесена в `app/styles/theme.css`; зерно тише; свечение за
  курсором и точечная сетка hero убраны.
- Карточки проектов переехали из `entities/project/ui` в
  `widgets/projects/ui`; `useRepos` — в `entities/repo`, один запрос на
  страницу.

### Исправлено

- Футер больше не обещает SQLite — база Postgres.
- Подсказка «подтвердите согласие» прячется после галочки.
- Pocacall переведён в архив без ссылки: домен не отвечает.
- Блокировка прокрутки под меню и модалками больше не затирает друг друга
  (`useScrollLock` со счётчиком).
- Снимок репозиториев обновлён и фильтруется как на сервере.
- Убраны непроверяемые числа («55+», «10+»).
